# Optional raw dataset downloads

The raw archives are intentionally not bundled with the application ZIP. Download them from the original repositories when you need ML training files.

- KneE-PAD: https://zenodo.org/records/12112951
- UCI Physical Therapy Exercises: https://archive.ics.uci.edu/dataset/730/physical%2Btherapy%2Bexercises%2Bdataset

After downloading, keep raw research data outside the web frontend's `public/` directory. Do not upload patient-identifying data to the application database.
